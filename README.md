# Knights-Travails

## Description

This project implements a graph-based solution to the Knight’s Travails problem in JavaScript. It models a standard 8x8 chessboard as an implicit graph, where each square represents a node and each valid knight move represents an edge. The core of the solution uses the Breadth-First Search (BFS) algorithm to find the shortest path between two positions on the board, ensuring the knight reaches its destination in the fewest moves possible.

### Prerequisites

- Node.js installed on your machine. Check it with the following command.

```bash
node -v
```

## Setup and Installation

1. Clone the repository
2. Open a terminal in the project directory and run the following command:

```bash
node knights-travails.js
```
